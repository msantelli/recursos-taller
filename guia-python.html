Instalar Python y manejar un proyecto con uv

Esta guía está pensada para quien nunca instaló nada: va de cero a un proyecto de Python funcionando, con un ejemplo chico de verdad. Son tres partes: instalar Python, entender (y si hace falta, arreglar) la variable PATH, y llevar un proyecto de punta a punta con uv.

1. Instalar Python por primera vez

Python es el lenguaje en que están escritas muchas de las herramientas que rodean a los modelos de lenguaje. Antes de usarlas hay que tener Python instalado — una sola vez por computadora.

¿Ya lo tengo?

Puede que sí: macOS y Linux suelen traerlo. Abrí una terminal y escribí: 

python3 --version

Si responde algo como Python 3.12.4, ya está: pasá directo a la parte 3. Si responde que no conoce el comando, seguí leyendo.

En Windows

  1. Descargá el instalador desde el sitio oficial: python.org/downloads.
  2. Al abrirlo, antes de tocar «Install Now», marcá la casilla «Add python.exe to PATH». Es una casilla chica abajo de todo, fácil de pasar por alto, y ahorra el problema más común de todos (explicado en la parte 2).
  3. Terminada la instalación, cerrá y volvé a abrir la terminal, y verificá con python --version.

La referencia completa es la guía oficial de Python para Windows (en castellano).

En macOS y Linux

Si python3 --version no respondió, descargá el instalador para tu sistema desde el mismo sitio oficial: python.org/downloads. En Linux también suele estar disponible con el gestor de paquetes de la distribución (por ejemplo, sudo apt install python3 en Ubuntu).

La alternativa: que uv lo instale por vos

La herramienta uv, que usamos en la parte 3, puede instalar Python por sí sola: si instalás uv primero, un uv python install descarga la última versión sin pasar por el instalador clásico. Para quien empieza de cero, es el camino con menos pasos.

2. La variable PATH (y el error más común)

Cuando escribís python en la terminal, la computadora tiene que encontrar el programa que se llama así. No revisa todo el disco: consulta una lista de carpetas donde buscar. Esa lista es la variable PATH. Pensala como el índice de una biblioteca: si un libro no figura en el índice, está en el edificio pero nadie lo encuentra.

El síntoma

"python" no se reconoce como un comando interno o externo,
programa o archivo por lotes ejecutable.

Este mensaje (o su variante command not found) casi nunca significa que Python no está instalado: significa que la carpeta donde quedó instalado no figura en el PATH. El libro está; el índice no lo lista.

Cómo arreglarlo

  1. El arreglo más simple (Windows): volvé a correr el instalador de Python, elegí «Modify» y asegurate de marcar la casilla «Add python.exe to PATH». Cerrá y volvé a abrir la terminal — los cambios al PATH solo se ven en terminales nuevas.
  2. El arreglo a mano: se puede editar el PATH desde la configuración del sistema, agregando la carpeta de Python. El procedimiento exacto está en la documentación oficial de Python sobre variables de entorno (en castellano).
  3. El arreglo por elevación: el instalador de uv configura el PATH solo. Si el PATH te está dando pelea, instalar uv y dejar que él maneje Python suele ser la salida más corta.

3. Un proyecto con uv, de punta a punta

uv es un gestor de proyectos de Python: crea la carpeta, aísla las dependencias (cada proyecto tiene las suyas, sin romper nada del sistema) y ejecuta los programas. Vamos a hacer un proyecto real aunque mínimo: un script que cuenta las palabras de un archivo de texto — un primer gesto de lectura distante. Seguimos los pasos de la guía oficial de proyectos de uv.

Paso 0: instalar uv

Una sola vez, con el comando que indica la página oficial de instalación para tu sistema. Al terminar, cerrá y abrí la terminal y verificá: 

uv --version

Paso 1: crear el proyecto

uv init contar-palabras
cd contar-palabras

uv init crea una carpeta con lo esencial. Los dos archivos que importan: pyproject.toml, la ficha del proyecto (su nombre, su versión de Python, sus dependencias — como la página de legales de un libro), y main.py, un programa de ejemplo que podés borrar.

Paso 2: escribir el script

Creá en la carpeta un archivo llamado contar.py con este contenido (con cualquier editor de texto; los comentarios explican cada línea): 

# contar.py — cuenta las palabras de un archivo de texto
# Uso: uv run contar.py mi-texto.txt

import sys                # para leer lo que se escribe tras el comando
from collections import Counter   # un contador de frecuencias ya hecho

# El nombre del archivo es lo que viene después de "contar.py"
archivo = sys.argv[1]

# Leemos todo el texto y lo pasamos a minúsculas
with open(archivo, encoding="utf-8") as f:
    texto = f.read().lower()

# Separamos en palabras (partiendo por espacios y saltos de línea)
palabras = texto.split()

print(f"El archivo tiene {len(palabras)} palabras.")
print("Las diez más frecuentes:")
for palabra, veces in Counter(palabras).most_common(10):
    print(f"  {palabra}: {veces}")

Paso 3: probarlo

Poné cualquier archivo .txt en la carpeta (por ejemplo, cuento.txt con un texto pegado de donde quieras) y corré: 

uv run contar.py cuento.txt

uv run se ocupa de todo: si el proyecto necesita un Python que no tenés, lo descarga; si hay dependencias declaradas, las instala; y recién entonces ejecuta el script.

Paso 4: agregar una dependencia

Las dependencias son librerías ajenas que el proyecto usa. Se agregan con uv add, que además las anota en pyproject.toml. Probemos con rich, que imprime tablas y colores en la terminal: 

uv add rich

Y al final de contar.py, reemplazá el bloque del print final por una tabla: 

from rich.table import Table
from rich.console import Console

tabla = Table(title=f"Palabras más frecuentes de {archivo}")
tabla.add_column("palabra")
tabla.add_column("veces", justify="right")

for palabra, veces in Counter(palabras).most_common(10):
    tabla.add_row(palabra, str(veces))

Console().print(tabla)

Corré de nuevo uv run contar.py cuento.txt y la lista sale en una tabla con bordes.

Paso 5: compartir el proyecto

Acá está el premio de haber usado uv: si le pasás la carpeta a otra persona (o la subís a un repositorio), a esa persona le alcanza con: 

uv sync

Ese comando lee pyproject.toml e instala exactamente lo que el proyecto declara — mismo Python, mismas librerías, mismas versiones. Es la diferencia entre prestar un libro y prestar la biblioteca entera ya ordenada.

Resumen de los cinco comandos

uv init mi-proyecto   # crear un proyecto nuevo
uv add libreria       # declarar una dependencia
uv run programa.py    # ejecutar (instala lo que falte)
uv sync               # reconstruir el entorno de un proyecto ajeno
uv python install     # instalar Python, si hiciera falta
